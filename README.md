# TAMU-CC Sewer System Simulator (restricted edition)

Dry-weather wastewater on the Texas A&M University–Corpus Christi campus, from an agent-based model coupled to EPA SWMM 5.2.4, running entirely in the browser. This edition shares pipe lengths and diameters and manhole depths only; model files are not offered for download. See about.html and LICENSE.md.

Bishal Khatri and Hua Zhang, Texas A&M University–Corpus Christi.
